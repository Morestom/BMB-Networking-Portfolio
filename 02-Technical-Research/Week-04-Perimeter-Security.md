# Week 04 — Perimeter Security and Firewall Architecture

The fourth week examined how security boundaries and firewall policies are used to separate networks with different trust requirements.

## Topics studied

- Network segmentation, security zones and trust boundaries.
- Perimeter and data-center firewalls.
- Stateful filtering and next-generation firewall capabilities.
- Network address translation and firewall-policy evaluation.
- SSL/TLS inspection concepts and VPN technologies.
- FortiGate interfaces, routing, NAT, firewall policies, security profiles, logging and troubleshooting.
- Logical enterprise security architecture for users, public-facing services and protected server networks.

The FortiGate material was research and architecture documentation, not a verified hands-on FortiGate deployment.
