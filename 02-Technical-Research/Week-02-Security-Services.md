# Week 02 — Security Services, Identity and Application Security

This week's research examined how enterprise security controls protect identity, network communications, endpoints and applications.

## Topics studied

- Cryptographic techniques, digital certificates, PKI and the TLS handshake.
- Authentication, Authorization and Accounting (AAA), including RADIUS and TACACS+.
- Site-to-site and remote-access VPN architectures.
- Email security and common phishing threats.
- EDR, NDR and XDR concepts.
- Vulnerability management, CVE and CVSS, and the role of vulnerability-management tools.
- Web application firewalls and F5 BIG-IP architecture.

The work was research and technical documentation, not production deployment of these security technologies.
