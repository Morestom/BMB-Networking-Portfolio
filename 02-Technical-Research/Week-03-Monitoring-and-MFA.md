# Week 03 — Security Monitoring and Multi-Factor Authentication

This research focused on observing security-relevant activity and increasing confidence in user authentication.

## Topics studied

- Syslog and common network, endpoint and application log sources.
- SIEM log aggregation, normalization, event correlation and dashboards.
- SOAR concepts and incident-response workflows.
- Knowledge, possession and inherence as authentication-factor categories.
- Multi-factor authentication in enterprise environments.
- Cisco Duo authentication architecture, including primary and secondary authentication decisions.

The report considered how authentication controls and centralized monitoring complement each other. This was conceptual research rather than deployment of a SIEM, SOAR or Duo environment.
