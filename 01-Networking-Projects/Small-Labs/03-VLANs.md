# Lab 03 — VLAN Configuration

**Environment:** Cisco Packet Tracer

The lab addressed logical segmentation of a switched network. VLAN membership determines which Layer 2 broadcast domain receives an Ethernet frame; routed connectivity is needed for communication between separate VLAN networks.

**Technical areas:** VLAN creation, switch access ports, Layer 2 segmentation.
